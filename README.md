# Assistente-de-Delivery-com-AWS-Step-Functions-e-Berdrock
Um assistente de Delivery que por meio de uma ideia sugerida pelo cliente seja para jantar ou para qualquer outra refeição solicitada, sugere pratos e acompanhamentos com base na ideia proposta e finaliza o pedido com a sugestao escolhida enviando no email uma confirmação de pedido e status de entrega.
